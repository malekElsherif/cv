What it does

A platform for property sale and rental listings. Users browse and filter listings, agents publish and manage them, and admins approve what goes live. I built the backend and a lightweight React client on top of it.

  • REST API with NestJS and TypeORM on PostgreSQL: create, edit and filter listings, plus an admin approval workflow.
  • JWT authentication and role-based access control for three roles: User, Agent and Admin.
  • Real-time chat over WebSockets.
  • Agent and admin dashboards to manage properties and user requests.
  • Containerized with Docker and deployed on Railway.
